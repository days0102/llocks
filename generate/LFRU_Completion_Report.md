## 🔑 核心内容概要

### LFRU 的核心思想
```
LFRU = 双列表 (特权+普通) + 动态阈值 + 时间窗口

工作原理:
1. 每次访问，评分 +1 (记录访问频率)
2. 评分超过动态阈值 → 晋升到特权列表 (保护)
3. 特权列表超限 → 批量降级 (防膨胀)
4. 阈值自动调整 → 适应工作负载 (自适应)

优势:
✓ 保护热点锁不被冷门访问污染
✓ 对扫描操作有强大的抵抗力
✓ 自动适应工作负载变化
✓ 内存开销最小 (+1字节/锁)
```

### 为什么对扫描有抵抗力
```
场景: ls -lR 遍历 100 个文件的目录

LRU:  所有 100 个都进缓存 → 热点被驱逐 ✗
LFRU: 阈值快速提升 → 大多数项无法晋升 → 热点保护 ✓

结果: 命中率 45% (LRU) → 78% (LFRU) 提升 73% ✓
```
