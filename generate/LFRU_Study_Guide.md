## 💡 学习技巧

### 1. 边读边画
在阅读时，自己画一个缓存的状态图：
```
┌──────────────────┐
│   特权列表(2)    │ Lock-A(3) → Lock-B(2)
│                  │
│   普通列表(8)    │ Lock-C(1) → Lock-D(1) → ...
└──────────────────┘
阈值 = 2, 窗口 = 3/10
```

### 2. 代码跟踪
拿一个具体的场景（如访问 10 个锁），跟踪每个函数的调用和变量变化。

### 3. 对比学习
同时打开 LRU 的实现（文件开头），理解 LFRU 相比增加了什么。

### 4. 写伪代码
用自己的语言和逻辑重写一遍算法，不看答案。

### 5. 提出问题
如果有不懂的地方，试着自己推导，想想为什么要这样设计。

  - 链接: https://arxiv.org/abs/1702.04078

### 其他缓存算法
- **LRU**: 基础算法，本文档的第一部分涉及
- **LFU**: 纯频率算法，与 LFRU 对比
- **ARC (Adaptive Replacement Cache)**: 另一个自适应缓存算法
- **CLOCK**: 时钟算法，硬件常用
